# Demo v2 Build

## Pages
Home, About, Founder, Faculty, Schools, Programmes, CCNA detail, Admissions, Contact, Online learning, Community, News, Article, FAQ, and school detail pages in `demo/`.

## File structure and editing
- `demo/*.html`: page shells and cache-busted references.
- `demo/assets/js/data.js`: shared config, schools, programmes, faculty, stats, and photos.
- `data-founder.js`, `data-programs.js`, `data-about.js`: page data.
- `main.js`: shared header, footer, navigation, and interactions.
- `assets/css/`: shared and page-specific styles.

Edit data files first and update [[Client Facts (Confirmed)]] with any future confirmed facts. Keep unknown secondary-course, testimonial, schedule, image, and contact details labelled to be confirmed. Do not add Cisco logo files; use text and styled chips.
